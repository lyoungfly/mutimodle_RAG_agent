这三项应该怎么填？

Base URL · API 基础地址
复制服务商文档中的 API 地址，不是聊天网页的地址。系统会自动拼接 /chat/completions；如果粘贴了完整接口地址，会自动去掉这一段。保留服务商要求的路径，例如 /v1。
Model · 模型名称
原样复制控制台或接口文档中的模型 ID，注意大小写。它可能与产品展示名称不同。本地服务填写启动时设置的模型名或服务别名。
API Key · 访问密钥
填写服务商控制台创建的密钥，不是账户密码，也不用加 Bearer。已保存后留空表示保留；要移除密钥请勾选“清除已保存的密钥”。本地服务未启用鉴权时可以留空。
填写示例与官方说明

DeepSeek 回答模型：地址填 https://api.deepseek.com，模型 ID 按控制台当前可用模型填写，密钥在服务商控制台创建。官方接入说明 ↗

本地兼容服务：例如 http://127.0.0.1:8001/v1，端口以实际启动参数为准，模型名称填已部署的服务名。vLLM 官方说明 ↗

视觉模型：必须支持图片输入与兼容的 Chat Completions 接口；可以与回答模型使用同一服务，但需在下方单独填写。同一家服务商的纯文本模型未必能看图。

测试失败时检查什么？

401：检查密钥；403：检查模型授权；404：核对基础地址和模型 ID；429：检查额度或稍后重试；超时：确认网络正常，本地服务已启动。测试通过仅代表此次接口请求成功，结构化回答和图表识别效果需用文献验证。
